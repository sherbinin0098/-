Политика конфиденциальности приложения «Проверка авто»

Действует с 23 октября 2026 года.

Коротко. Приложение помогает проверять, есть ли машина в федеральном реестре инвалидов (ФРИ), и вести собственный список проверок. Все записи и фото хранятся на вашем телефоне. Разработчик не получает ваши данные и не имеет своего сервера. Приложение не связано с Госуслугами, ФГИС ФРИ и государственными органами; сама проверка выполняется на официальном сайте gosuslugi.ru.

Какие данные обрабатываются

  • Ваши записи: госномера машин, результаты проверки, место, дата и время, заметки, имя автора записи, если вы его указали.
  • Фото: фото машин и скриншоты проверки, которые вы сами добавляете с камеры или из галереи.
  • Местоположение: координаты, только когда вы пользуетесь приложением и разрешили геолокацию, чтобы отметить место проверки и подсказать адрес.
  • Голос: если вы нажимаете кнопку микрофона, речь распознаётся системной службой распознавания речи телефона (обычно Google), чтобы получить госномер. Приложение не хранит запись голоса.

Где хранятся данные

Записи и фото хранятся только в памяти приложения на вашем телефоне. При удалении приложения они удаляются. Копию вы можете сохранить сами: в файл, в таблицу Excel или в свой Google Диск.

Кому передаются данные

  • OpenStreetMap (Nominatim) и Photon (komoot): координаты и текст, который вы вводите в поле «Место», отправляются этим картографическим сервисам, чтобы определить адрес и найти магазины и адреса рядом. Карта загружается с серверов OpenStreetMap, библиотека карты (Leaflet) — с общедоступных CDN (unpkg, cdnjs, jsDelivr).
  • GitHub Pages: страница приложения загружается с сервиса GitHub Pages (GitHub, Inc.). Как любой хостинг, он получает технические данные запроса (IP-адрес, тип браузера). Ваши записи туда не передаются.
  • Google Диск: только если вы сами нажали «Войти через Google». Тогда копия записей с фото и таблица сохраняются в ваш Google Диск, в папку «Проверка авто». Приложение получает доступ только к файлам, которые создало само (разрешение drive.file), и не видит другие ваши файлы.
  • Распознавание номера по фото и результата на скриншоте проверки выполняется прямо на телефоне (Google ML Kit), фото и скриншоты для этого никуда не отправляются.
  • Госуслуги: приложение копирует номер и открывает официальную страницу проверки в браузере. Что вы делаете на сайте Госуслуг, регулируется правилами этого сайта.
  • Когда вы нажимаете «Отправить», файл передаётся выбранному вами приложению (мессенджеру, почте и т. п.).
  • Написать автору: только если вы сами нажмёте кнопку отправки в разделе «Ещё». Текст уходит выбранному вами приложению (мессенджеру, Telegram или почте). Можно выбрать «Ответ не нужен»: тогда имя и контакт в текст не попадают. Если вы отметите «Это ошибка в приложении», к тексту добавятся диагностика (версия приложения, модель телефона, последние сообщения и ошибки) и, по вашему выбору, карточка одной машины. При проверке адреса почты для ответа служба DNS Cloudflare (cloudflare-dns.com) получает только доменную часть адреса (например, mail.ru), чтобы убедиться, что такой домен существует. Автоматически ничего не отправляется.

Приложение не показывает рекламу, не использует аналитику и не продаёт и не передаёт данные кому-либо ещё.

Ответственное использование

Фото и номера машин — это сведения о других людях. Публикуйте их только в рамках закона, закрывайте лица и посторонние номера.

Удаление данных

Любую запись можно удалить в приложении: «История» → машина → «Удалить». Все данные удаляются вместе с приложением или через «Настройки Android → Приложения → Проверка авто → Хранилище → Очистить данные». Файлы в Google Диске удаляются в самом Google Диске; доступ приложения к Диску можно отключить кнопкой «Отключить» или на странице myaccount.google.com/permissions.

Дети

Приложение не предназначено для детей младше 13 лет.

English summary. “Proverka avto” keeps all records and photos on the device only; the developer runs no server and receives no data. The app page is served by GitHub Pages, which, like any host, receives technical request data (IP address, browser type). Location is used only while the app is in use, to mark the place of a check; coordinates and typed place names are sent to OpenStreetMap Nominatim and Photon (komoot) to look up addresses; map tiles come from OpenStreetMap and the map library (Leaflet) from public CDNs. Optional Google Drive sync stores a backup in the user’s own Drive using the drive.file scope. Plate recognition and reading of the check result from a screenshot run on-device (ML Kit). Voice input uses the system speech recognizer. The “Write to the author” form (wishes, questions, bug reports) sends text only through an app the user picks (messenger, Telegram or email) and can be anonymous; if “This is an app error” is ticked, diagnostics (app version, phone model, recent messages and errors) and optionally one car record are added. When a reply e-mail is checked, only its domain is looked up through Cloudflare DNS. Nothing is sent automatically. No ads, no analytics, no data sales.
